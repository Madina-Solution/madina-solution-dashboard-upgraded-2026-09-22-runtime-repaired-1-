# MADINA SOLUTION — Stability, Editor, Navigation & Performance Upgrade

## Data safety
- Existing article rows are preserved; no delete/reset/migration-destructive operation is introduced.
- Runtime schema guard adds `articles.metadata` and `products.metadata` only when missing, using `IF NOT EXISTS`.
- Existing title, slug, excerpt, content, thumbnail, category, tags, publish state and timestamps remain untouched.

## Content editor
The reusable `RichTextEditor` is now used for long-form content in:
- Articles
- Products
- Services
- Portfolio / case studies
- FAQs
- Testimonials
- Homepage hero description

Short fields such as SEO meta descriptions remain plain text controls where appropriate.

## Desktop navigation
Desktop Mega Menu now intentionally uses different information architectures:
- Layanan: service discovery and brand-building journey.
- Produk: catalog/category grid plus custom-product CTA.
- Eksplor: editorial/company destinations plus consultation.

Mobile and desktop use the same database navigation source, but present it in context-appropriate layouts instead of duplicating the same cards.

## Branding
Configured PNG/SVG logos no longer render inside a forced square button-like container. The logo preserves transparent canvas and natural aspect ratio.

## Performance
- Removed Framer Motion from header desktop mega menu and mobile navigation.
- Replaced menu motion with lightweight CSS/conditional rendering.
- Hero image quality/sizes tuned for mobile delivery.
- Cookie consent and AdSense state are hydration-safe.

## Runtime database compatibility
Older deployments where `articles.metadata` is missing no longer crash public `/blog` or admin article APIs. The additive runtime schema guard upgrades the table without removing article data.
